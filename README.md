# FleetTribe — Fleet Intelligence Platform

FleetTribe is a fleet intelligence platform developed as part of the **VexarDrive Technologies — Data Science Intern Assignment**. It transforms driver behaviour and vehicle telemetry into explainable risk and maintenance insights.

## Project Structure
*   **`analysis/`**: Python analytical pipeline scripts (data validation, feature engineering, and scoring).
*   **`docs/`**: Project requirements, rules, and technical explanations.
*   **`app/`**: Next.js dashboard application (TypeScript + Tailwind CSS).
*   **`LOGGER.md`**: Chronological engineering and decision log.
